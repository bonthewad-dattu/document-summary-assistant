# Document Summary Assistant

A web application that extracts text from PDFs and images, then generates intelligent summaries using AI.

## Features
- 📄 PDF text extraction
- 🖼️ OCR for images
- 📝 AI-powered summaries with length options
- 🎯 Key points highlighting
- 📱 Mobile-responsive design

## Tech Stack
- Next.js 14
- TypeScript
- Tailwind CSS
- Tesseract.js (OCR)
